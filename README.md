# CarSift

אפליקציה רספונסיבית בעברית להשוואת רכבים משומשים בישראל. הממשק נפתח לכל מי שיש לו את הקישור; מסד הנתונים נגיש רק למשתמשים שאומתו ונוספו לרשימת החברים.

## מה כלול

- סינון מתקדם: יצרן ודגם (בחירה מרובה), טווח מחיר ב-₪ (סרגל כפול), שנתון מינימלי, קילומטראז׳ מקסימלי, הנעה (בנזין / דיזל / היברידי / חשמלי), יד, ורשימת אבזור (גג שמש, מושבי עור, מצלמת רוורס, שיוט אדפטיבי ועוד).
- מיון לפי התאמה, מחיר, שנתון, קילומטראז׳ או תאריך הוספה.
- מגירת השוואה תחתונה לעד 3 רכבים, ועמוד השוואה מלא עם הדגשת הערך הטוב ביותר בכל שורה.
- חלון פרטים מלא לכל רכב: נתונים, אבזור, הערכה, הערות וקישור למודעה.
- מועדפים: ב-localStorage בלי Supabase; עם Supabase אפשר לבחור בעמוד הפרופיל בין סנכרון לחשבון לשמירה במכשיר (ברירת מחדל ב-`FAVORITES_STORAGE` ב-`config.js`).
- כל המחירים מוצגים בשקלים (₪) בפורמט he-IL.
- מאגר רכבים משותף, עם קישורי מודעות, הזנה ידנית וייבוא מתוך טקסט OCR.
- כניסה אישית באמצעות קישור חד־פעמי למייל של Supabase Auth.
- פרופיל חיפוש אישי, משקלים, מועדפים וציוני התאמה נפרדים לכל משתמש.
- בחירת רכבים והשוואה זה לצד זה.
- ייבוא וייצוא JSON.
- OCR מקומי בדפדפן באמצעות Tesseract.js; התמונה לא נשלחת לשרת.
- מצב הדגמה מקומי בדפדפן כש-Supabase עדיין לא הוגדר.

## הגדרה

1. צרו פרויקט Supabase בחבילה החינמית והריצו את `supabase/schema.sql` ב-SQL Editor. אם המסד כבר קיים, הריצו את הקובץ שוב — הוא מוסיף את עמודת `features` בלי למחוק נתונים.
2. צרו `config.js` לפי `config.example.js` והכניסו את כתובת הפרויקט ואת ה-anon/publishable key. הקובץ מוחרג מ-Git.
3. הגדירו ב-Supabase Auth את כתובת האתר ואת כתובת GitHub Pages ככתובות redirect מותרות, והפעילו כניסה במייל.
4. כל משתמש מאושר נכנס פעם אחת דרך קישור המייל. לאחר מכן הוסיפו אותו ל-`public.members` באמצעות שאילתת ההזמנה שמופיעה בסוף `schema.sql`. חשבונות שלא נוספו לרשימה אינם יכולים לקרוא או לשנות את המאגר.
5. ב-GitHub, הגדירו **Settings → Pages → Build and deployment → Source: GitHub Actions**. ה-workflow יפרוס אוטומטית כל push ל-`main`.

אין להכניס מפתח `service_role` לקובץ בדפדפן. המפתח הציבורי בלבד משמש את האפליקציה, וכל הגישה מוגנת על ידי RLS.

## מגבלות ידועות

- קישורי מודעות נשמרים ברכב, אך אתרי מודעות רבים חוסמים קריאה ישירה מהדפדפן (CORS, התחברות או הגנת בוטים). לכן אפשר להדביק את טקסט המודעה או להעלות צילום מסך; חילוץ אוטומטי של דף מודעה מחייב פונקציית שרת מותאמת לאתר ולרוב דורש תחזוקה.
- OCR רץ בדפדפן, ללא API בתשלום. טעינת מנוע ושפה עברית דורשת חיבור CDN בפעם הראשונה.
- בלי פרטי Supabase, הנתונים נשמרים מקומית בדפדפן ואינם מסתנכרנים בין משתמשים או מכשירים.
- פרטי Supabase נדרשים למאגר המשותף, לכניסה ולפרופילים נפרדים. אין תלות בשירות AI בתשלום.

## הפעלה מקומית

אפשר לפתוח את התיקייה עם שרת קבצים סטטי. אם Supabase לא הוגדר, CarSift יעלה בלי Supabase וישמור שינויים ב-localStorage של הדפדפן.
